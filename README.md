## 🔍 OSINT & Recherche

### Shodan
🔍 Recherche: `shodan`, `iot`, `port scan`, `internet scanner`, `actifs exposés`
- Rechercher un IP : `https://www.shodan.io/host/{IP}`
- Filtrer par port/pays : `port:22 country:MA`
- Trouver un service : `product:"Apache" org:"SUEZ"`
- Télécharger les résultats : `shodan download results.json "query"`
